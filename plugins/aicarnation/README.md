# AIcarnation（Claude Code プラグイン・試作）

Claude Code（と Claude Desktop のチャット）で話している間、横の小窓の 3D アバター（VRM）が表情・動き・読み上げで反応するプラグインです。
API キーも `pnpm dev` も要りません。モデルの呼び出しは Claude Code 自身のもの（haiku / sonnet）を使います。

| Claude Code で起きたこと | アバターの反応 |
|---|---|
| あなたが話しかけた | 吹き出しに発言を出し、「考え中」にする |
| ツールを使っている | 「ファイルを書き換えています」などの様子を出す |
| 返答が終わった | 「まとめています」→ 返答を1〜3文に要約し、選択中のエージェントの口調・表情で読み上げる |

## 入れ方

必要なもの：

- Claude Code（デスクトップアプリかターミナル版。入れるときはターミナルの `claude` コマンドを使います）
- [Node.js](https://nodejs.org/) 18 以上（アバターの画面を出す小さなサーバーを動かすのに使います）
- パソコンの Chrome か Edge（Safari は小窓の機能が限られます。Firefox とスマートフォンには対応していません）

入れ方は、次の3つの手順です。Claude Code と Claude Desktop のチャットの両方で、アバターが反応するようになります。

**1. Claude のアプリを終了する**（Windows はタスクトレイのアイコンから「終了」、Mac は ⌘Q）

**2. ターミナルで、次の3つを順に実行する**（Windows は PowerShell、Mac はターミナル。どちらも同じ文をそのまま貼れます）

```
claude plugin marketplace add webasu-git/AIcarnation
```

```
claude plugin install aicarnation@aicarnation
```

```
node "$HOME/.claude/plugins/marketplaces/aicarnation/plugins/aicarnation/server/setup-desktop.mjs"
```

**3. Claude のアプリ（または Claude Code）を開いて、プラグインを再読み込みする**

```
/reload-plugins
```

- 手順 3 の再読み込みは必ず行ってください。行わないと、入れたプラグインが反映されません。
- 手順 2 の3つ目のコマンドは、Claude Desktop のチャットへの登録です。Claude のアプリを起動したまま実行すると、アプリを終了するときに登録が消えてしまうので、必ずアプリを終了してから実行してください（起動中は、登録せずに知らせます）。
- Windows では、コマンドプロンプト（cmd）ではなく PowerShell で実行してください（`$HOME` が自分のフォルダに置き換わるのは PowerShell です）。
- Claude のデスクトップアプリの中で `/plugin` と打つと、プラグインを選ぶ画面に切り替わり、コマンドとしては動きません。入れるときは、必ずターミナルで実行してください。
- `claude: command not found` と出る場合は、ターミナル版の Claude Code を入れてください（[Claude Code の入れ方](https://code.claude.com/docs/en/setup)）。

再読み込みしたら `/aicarnation` でアバターの画面が開きます（下の「使い方」）。

## このプラグインがすること

- **パソコンの中だけで動くサーバー**：Claude Code のセッションが始まると、アバターの画面を出すサーバーを `127.0.0.1:48280` で起動します。このパソコンの中からしか届かず、使うには合言葉（自動で作られます）が必要です。セッションが終わると止まります。
- **音声エンジン**：AivisSpeech を入れていれば、アバターの画面を開いたときにエンジンを起動します（このパソコンの中で動きます）。
- **ダウンロード**：自動では何もダウンロードしません。`/aicarnation-voice install aivis yes` と打ったときだけ、AivisSpeech の公式のリリース（GitHub）からエンジンを取得し、公開されている SHA-256 と照らし合わせます。
- **Claude Desktop の設定**：Claude Desktop のチャットに登録するコマンド（`setup-desktop.mjs`）を実行したときだけ、Claude Desktop の設定ファイル（`claude_desktop_config.json`）に `aicarnation` の項目を足します。書き換える前の設定は、同じフォルダに控えとして残します。
- **外に送るデータ**：返答の要約、キャラクター設定の作成、声のおすすめ、台詞の作成には、Claude Code 自身のモデルを使います（Claude Code の利用量の範囲です）。それ以外に、会話やファイルをどこかへ送ることはありません。利用状況などの送信もありません。
- **保存するデータ**：キャラクター・設定・会話履歴・読み込んだ素材は、このパソコンの保存先フォルダ（下の「データの置き場所」）にだけ置きます。

## しくみ

```
Claude Code ── mod（hooks/register.ts）
                 │ セッション開始時に起動 ($.process.spawn)
                 ▼
          server/aicarnation-server.mjs（127.0.0.1:48280、Node 18 以上）
                 │ 画面の配信・合図の SSE・画面からのモデル依頼の中継
                 ▼
          web/（アバター画面。Chrome / Edge の小窓で常に手前に置ける）
```

- サーバーは `127.0.0.1` だけで待ち受け、API には合言葉が必要です。サーバーは1つを共用します。すでに同じ版のサーバーが動いていれば（ほかの Claude Code のセッションや Claude Desktop が起動したもの）それを使い、起動したセッションが終わってサーバーが止まったときは、次の `/aicarnation` で起動し直します。
- アバターは、どちらで開いても、Claude Code と Claude Desktop のチャットの両方の会話に反応します（同時に話しかけたときは、新しい出来事に合わせて動きます）。
- 画面からのエージェント生成・声の推薦は、サーバー経由で mod に頼み、Claude Code のモデルで答えます（画像からの生成は使えません）。mod は扱える依頼を名乗って取りに行くので、Claude Code を複数開いていて版が混ざっていても、依頼はそれを扱えるセッションにだけ渡ります。
- アバターを開いていないときは、要約のためのモデル呼び出しをしません。

## 言語について

- 画面の表示と案内は日本語だけです。
- 声（AivisSpeech）は日本語の音声合成です。英語などの文も日本語の読みで話します。
- 返答の要約は、Claude Code での会話が何語でも、アバターは日本語で話します（チャットの本文はそのままです）。
- 音声入力（マイクで話しかける）は、ブラウザの言語に合わせて聞き取ります。

## 自然な声で話させる（任意）

[AivisSpeech](https://aivis-project.com/) を使うと、エージェントの「編集 → ③ 声 → 声の出し方」で選べます（無料で、この PC の中で動きます）。
入っていれば、アバターの画面を開いたときにプラグインが起動し始め（セッションの間だけ）、起動を待ってから話し始めます（あいさつも待ちます）。入っていないときや起動できないときは、ブラウザの声で読み上げます。

エンジンは自動ではダウンロードしません。入れるときは Claude Code で次のように打ちます。

| コマンド | すること |
|---|---|
| `/aicarnation-voice` | エンジンが入っているか、どこに入れるかを表示 |
| `/aicarnation-voice install aivis` | AivisSpeech のファイル名・取得元・サイズ（Windows で約 217 MB）を表示 |
| `/aicarnation-voice install aivis yes` | 上で表示したものをダウンロードして入れる（進み具合はステータス行） |

入れる場所は保存先フォルダ（下記）の `engines/` です。公式のインストーラーで入れたものを使うときは、環境変数 `AICARNATION_AIVIS_ENGINE` に実行ファイル（`run.exe` / `run`）の場所を指定してください。

### 声のモデル（.aivmx）

声そのものは AivisSpeech の音声合成モデル（`.aivmx`）です。アバターの画面の「素材」タブ →「声のモデル」で `.aivmx` を追加・外すと、エージェントの「声」で選べる話者が増減します（AivisSpeech の `/aivm_models` を使います）。一覧が正しく出ないときは、同じ欄の「AivisSpeech を再起動する」で起動し直せます。
感情タグに合わせて声の抑揚とテンポが変わり（エージェントの「③ 声」で調整・オフにできます）、読み間違いは「素材」タブの「読みの辞書」で直せます。
このプラグインは声のモデルを含みません。モデルはご自分でご用意のうえ、それぞれのライセンス（ACML / ACML-NC / CC0、個別の規約など）に沿ってお使いください。

AivisSpeech は、起動するたびに標準の声（コハク・まお）を AivisHub から入れ直します。外すことはできませんが、ライセンスは ACML 1.0（個人・商用とも利用でき、クレジットは任意）なので、そのまま使っても問題ありません。エージェントの「声」の一覧では「最初から入っている声」として分けて表示します。

## 素材の入れ方

このプラグインは素材（3D モデル・声・動き）を含みません。ご自分でご用意いただき、それぞれのライセンスや規約（再配布の可否・クレジット・商用利用など）をお確かめのうえ、お使いください。何も入れなくても、標準の小さな動きとブラウザの声で動きます（3D モデルが無い間は、声と吹き出しだけで話します）。

アバターの画面の設定は4つのタブに分かれています。最初は「キャラクター」タブの上の「はじめに」に、追加する順番が出ます。

| タブ | すること |
|---|---|
| キャラクター | キャラクター（見た目・背景・人格・声・動き・アイコンをひとまとめに持つ）の作成・切り替え・複製・書き出し。3D モデル（.vrm）を追加する、背景を単色か画像・動画（壁紙やイラストなど）にする、人格と声を編集する |
| 動き | 動きのファイル（.vrma・Mixamo の .fbx）を役ごとに追加する。話すときの手ぶりのオン・オフ |
| 素材 | 声のモデル（.aivmx）の追加・外す・AivisSpeech の再起動、読みの辞書、素材の入手先の案内 |
| 設定 | 読み上げと音量、ひとりのときの身ぶりの多さと居眠り、画面のテーマ（システム／ライト／ダーク）、吹き出し、カメラ |

| 素材 | 入手のしかた（例） |
|---|---|
| 3D モデル（.vrm） | [VRoid Studio](https://vroid.com/studio) でご自分で作れます。配布されているモデルは、モデルごとの利用条件に従ってお使いください |
| 声（.aivmx） | [AivisHub](https://hub.aivis-project.com/) で入手できます。ライセンスはモデルごとに異なります |
| 動き（.vrma・.fbx） | [Mixamo](https://www.mixamo.com/) からご自分でダウンロードした FBX をそのまま追加できます（元ファイルの再配布はできません） |

動きは、複数のファイルやフォルダをまとめて追加すると、ファイル名の先頭の印（`(待機)` `(考える)` `(作業中)` `(話す)` `(挨拶)` `(喜ぶ)` `(気まぐれ)`）で役に振り分けます。

### 標準の動き

動きのファイルを入れていない役は、どのモデルでも崩れにくい小さな動きで動きます。腕を使う動きや大きな動きは、動きのファイルでお入れください。

- いつも：重心の移動、呼吸、まばたき、視線、マウスを目で追う
- 会話の様子：聞いている・考え中・作業中は頭と上半身の傾き、話している間は両手を開いて見せる手ぶり（キャラクターごとにオフにできます）と、文の終わりのうなずき
- 感情：表情と口の形、体のわずかな傾き
- ひとりのとき：見回す・首かしげ・ほほえむ・リズムに乗る・あくび、長く話しかけないと居眠り（多さと居眠りは「設定」タブで変えられます）

### 書き出しと読み込み

キャラクターの「書き出し」は設定だけ（人格・声の設定・動きの割り当て・読みの辞書・背景とアイコンの見せ方）で、3D モデル・動きのファイル・声のモデル・背景とアイコンの画像は入りません。読み込んだ側では、足りない素材が案内に出るので、同じものをご用意のうえ追加してください（同じ名前の動きのファイルは元の役に入り、同じ名前のアイコンの画像は元の位置と大きさに戻ります）。

## データの置き場所

プラグインが使うものは、すべて保存先フォルダ `~/.claude/plugins/data/aicarnation/`（Windows は `%USERPROFILE%\.claude\plugins\data\aicarnation\`）に置きます。プラグインを更新しても残り、フォルダごと消せば跡は残りません（アンインストールしても自動では消えないので、要らなくなったらこのフォルダを削除してください）。

| フォルダ | 中身 |
|---|---|
| `data/` | キャラクター・設定・会話履歴・読み込んだ VRM と動きのファイル（ブラウザには保存しないので、どのブラウザで開いても同じ） |
| `engines/` | `/aicarnation-voice` で入れた音声エンジン |

対応 OS は Windows と macOS です（Node 18 以上が必要）。mac で node が見つからないときは、環境変数 `AICARNATION_NODE` に node の場所を指定してください。

## 使い方

1. 上の「入れ方」でプラグインを入れる
2. `/aicarnation` を実行する → ブラウザでアバターが開く（Chrome / Edge なら「小窓で開く」で常に手前に）
3. そのまま Claude Code で話しかける

ステータス行に「アバター：/aicarnation で開けます」と出ていれば起動済みです。「サーバーを起動できません」と出るときは Node 18 以上を入れてください。

## Claude Desktop のチャットで使う（試作）

Claude Code のプラグインを入れただけでは、Claude Desktop のチャットにはアバターが反応しません。Claude Desktop のチャットには会話を外に知らせる仕組みが無いので、アバターの MCP サーバーを Claude Desktop に登録し、Claude にツールを呼んでもらいます。

| ツール | Claude が呼ぶとき | すること |
|---|---|---|
| `aicarnation_open` | 「アバターを開いて」と頼まれたとき | アバターの画面をブラウザで開く。画面で選んでいるキャラクターの設定を Claude に返す |
| `aicarnation_listen` | 返答のたびに最初に | あなたの発言の要約を吹き出しに出し、アバターがうなずいて「考え中」になる |
| `aicarnation_say` | チャットに返答の本文を書き始める直前 | 返答の要点（1〜3文・200文字まで・感情タグ付き）をアバターが声と表情で話す。結果で「本文をすべてチャットに書いて」と促す |

チャットにはいつもどおり返答の全文が残り、アバターは要約だけを話します。

登録は、上の「入れ方」の手順 2 の3つ目のコマンドで行います（最初に一度だけ）。あとから登録するときも、Claude のアプリを終了してから、ターミナルで同じコマンドを実行してください。

```
node "$HOME/.claude/plugins/marketplaces/aicarnation/plugins/aicarnation/server/setup-desktop.mjs"
```

- 書き換える前の設定ファイル（`claude_desktop_config.json`）を同じフォルダに控えとして残し、`mcpServers` の `aicarnation` の項目だけを足します（ほかの設定には触りません）。
- 登録するのは、`claude plugin marketplace add` で取り込まれた場所の MCP サーバーです。`claude plugin marketplace update` で中身が新しくなっても場所は変わらないので、登録し直す必要はありません。
- Claude Code で `/aicarnation-desktop` を実行すると、この登録のしかたを表示します。
- 登録を外すときは、同じコマンドの最後に ` --remove` を付けて実行します。
- 一度登録すれば、Claude Code の `/aicarnation` で開いても、チャットの「アバターを開いて」で開いても、同じアバターが両方の会話に反応します（保存先と合言葉は `~/.claude/plugins/data/aicarnation` で共通です）。

- 画面と同梱サーバーは Claude Code 版と共通です。Claude Code が起動していればそのサーバーを使い、いなければ MCP サーバーが起動します（Claude Desktop を閉じると止まります）。合言葉は保存先の `token` で共通なので、サーバーが入れ替わっても開いている画面はそのままつながり直します。
- Claude がツールを呼ぶかどうかはモデルしだいで、呼び忘れることがあります。確実にしたいときは、プロジェクトの指示に「返答のたびに aicarnation_say を呼ぶ」と書いてください。ツールの呼び出しはチャットの利用量を少し使います。
- エージェントの生成・声のおすすめ・台詞帳の作成は Claude Code のモデルを使います。Claude Desktop のチャットから開いたときも、Claude Code のセッションが1つ動いていれば、そのセッションが答えるので使えます。Claude Code が動いていないときは使えません（台詞は既定のものになります）。
- claude.ai（ブラウザ版）からは、この PC の MCP サーバーに届かないので使えません。
- Claude Desktop に登録した MCP サーバーは、Claude Desktop の中の Claude Code にも読み込まれます。Claude Code ではプラグインが自動で反応するので、Claude Code の中では、プラグイン（mod）がアバターの MCP ツールの呼び出しを断ります（Claude Desktop の中の Claude Code は接続元を見分けられないため）。

## ソースから動かす（開発する人向け）

画面（`web/`）は `apps/web` のソースからビルドで作れます。

```bash
pnpm --filter @aicarnation/web build:companion
```

その後、`claude --plugin-dir <このフォルダの絶対パス>` で起動するか、環境変数 `CLAUDE_CODE_PLUGIN_DIRS` にこのフォルダを入れます。
